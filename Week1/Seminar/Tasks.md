# Семинар 1: Условия на задачи

<p><strong>Задача 1: </strong>Напишете програма, която въвежда от стандартния вход малка латинска буква и извежда на стандартния изход еквивалентната голяма латинска буква. Пример: </p>
Вход:

```
a
```
Изход:

```
A
```

Вход:

```
f
```
Изход:

```
F
```

<p><strong>Задача 2: </strong>Напишете програма,която въвежда от стандартния вход голяма латинска буква и извежда на стандартния изход еквивалентната малка латинска буква. Пример: </p>
Вход:

```
A
```
Изход:

```
a
```

Вход:

```
K
```
Изход:

```
k
```
