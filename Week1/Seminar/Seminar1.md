# Семинар 1: Променливи и типове данни. Основни оператори. Вход и изход

## Променливи и типове данни

Типове данни:
- целочислен тип - int, long long
- с плаваща запетая - float, double
- булев тип - bool
- символен тип - char

Променлива - част от паметта на компютъра, която е задалена и на която е дадено име. Контейнер за информация. 
Променливите имат следните характеристики:
- име (идентификатор)
- тип на данните
- стойност на данните
- обхват (scope)


Декларация на променлива:

```
<тип> <име>[ = <стойност>];
int number = 0;
long long number2;
float floatingPoint = 1.0;
double doublePrecision = 2.45;
bool flag = true;
char symbol = 'a';
```

Имената (идентификаторите) на променливите могат да съдържат:
- главни и малки латински букви
- цифри
- долни черти (_)

Имената на променливите НЕ могат:
- да започват с цифра
- да са запазени думи (като например int)
- да съдържат интервали

## Оператори

Операторите се използват, за да обработват променливите. Всеки оператор се характеризира със:
- приоритет: ако има няколко оператора в една команда, този с по-висок приоритет ще се изпълни първи
- асоциативност: ако има няколко оператора с еднакъв приоритет в една команда, те ще се изпълнят по ред според асоциативността си. Асоциативността е лява или дясна.
- операнди: елементите, които приема
- стойност на връщане: резултатът, който се предава след работа на оператора. Стойността на връщане има две характеристики:
    - тип на данните: типът на връщаната стойност. Един от типовете, изброен горе
    - lvalue/rvalue: lvalue означава стойност, която има адрес в паметта, променлива; rvalue е стойност, която няма адрес в паметта


### <strong>Аритметични оператори: </strong>
|Оператор |	Значение |	Пример |	Резултат | Асоциативност | Тип на връщане |
| ------- | -------- | ------- | --------- | ------------- | -------------- |
| + |	Събиране |	5 + 2 |	7 | лява | число (rvalue)
| - |	Изваждане |	5 - 2 |	3 | лява | число (rvalue)
| * | Умножение |	5 * 2 |	10 | лява | число (rvalue)
| / |	Деление |	5 / 2 |	2 | лява | число (rvalue)
| % |	Деление с остатък |	5 % 2 |	1 | лява | число (rvalue)

### <strong>Оператори за сравняване: </strong>

|Оператор |	Значение |	Пример |	Резултат | Асоциативност | Тип на връщане |
| ------- | -------- | ------- | --------- | ------------- | -------------- |
| == |	Равно |	5 == 2 |	false | лява | булев тип (rvalue)
| != |	Не равно |	5 != 2 |	true | лява | булев тип (rvalue)
| >= |	По-голямо или равно |	5 >= 2 |	true | лява | булев тип (rvalue)
| <= | По-малко или равно |	5 <= 2 |	false | лява | булев тип (rvalue)
| > |	По-голямо |	5 > 2 |	true | лява | булев тип (rvalue)
| < |	По-малко |	5 < 2 |	false | лява | булев тип (rvalue)

<strong>Сравняване на типове с плаващата запетая: НЕ </strong>сравняваме типове данни с плаваща запетая (float, double) с ==! Вместо това сравняваме дали абсолютната стойност на тяхната разлика е по-малка от приемлива за нас стойност за грешка:

```
double a = 1.0;
double b = 1.00;

double epsilon = 0.00002;

bool areEqual = std::fabs(a - b) < epsilon;
```

### <strong>Логически оператори: </strong>

|Оператор |	Значение |	Пример |	Резултат | Асоциативност | Тип на връщане |
| ------- | -------- | ------- | --------- | ------------- | -------------- |
| && |	Логическо И |	(5 < 2) && (5 > 4) |	false | лява | булев тип (rvalue)
| &#124;&#124; |	Логическо ИЛИ |	(5 < 2) &#124;&#124; (5 > 4) |	true | лява | булев тип (rvalue)
| ! |	Логическо НЕ |	!(5 > 2) |	false | лява | булев тип (rvalue)

Таблица със стойностите на логическите оператори:

| A |	B |	A && B |	A &#124;&#124; B | !A | !B |
| ------- | -------- | ------- | --------- | ------------- | -------------- |
| false |	false |	false |	false | true | true
| false |	true | false |	true | true | false
| true | false | false |	true | false | true
| true | true | true |	true | false | false


### <strong>Оператори за присвояване: </strong>

|Оператор |	Значение |	Пример | Еквивателнто на | Асоциативност | Тип на връщане |
| ------- | -------- | ------- | --------- | ------------- | ---------- |
| = |	Присвояване |	a = 5; | N\A | дясна | число, lvalue - лявата променлива
| += | Присвояване със събиране |	a += 5; | a = a + 5;	| дясна | число, lvalue - лявата променлива
| -= | Присвояване с изваждане |	a -= 5; | a = a - 5;	| дясна | число, lvalue - лявата променлива
| *= | Присвояване с умножение |	a *= 5; | a = a * 5;	| дясна | число, lvalue - лявата променлива
| /= | Присвояване с деление |	a /= 5; | a = a / 5;	| дясна | число, lvalue - лявата променлива
| %= | Присвояване със деление по модул |	a %= 5; | a = a % 5;	| дясна | число, lvalue - лявата променлива

### <strong>Декрементиране и инкрементиране: </strong>
Означава да променим стойността на променлива с точно 1. Има четири специални оператора, които постигат това: операторите за префиксно и суфиксно инкрементиране/декрементиране. 

При префиксното инкрементиране/декрементиране операторът стои пред променливата: ++i/--i. Еквивалентно на: i += 1/i -= 1. Асоциативност: дясна. Тип на връщане: число, lvalue - променливата i.

При суфиксното инкрементиране/декрементиране операторът стои след променливата: i++/i--. Асоциативност: лява. Тип на връщане: число, rvalue - старата стойност на i. Тоест, суфиксното инкрементиране/декрементиране променя стойността на променливата, но връща старата стойност като rvalue; промяната се "вижда" чак на следващата команда.

```
int a = 5;
int b = ++a; //a = 6, b = 6
int c = 5;
int d = c++; //c = 6, d = 5
```

## Вход и изход

Вход в програмата - данните се подават към програмата

Изход от програмата - данните се подават от програмата

std::cin - обект за вход от клавиатурата. Пример:

```
int a;
cin >> a; // а има стойност, подадена от клавиатурата
```

std::cout - обект за изход на конзолата. Пример:

```
int a = 0;
cout << a; //извежда стойността на а на конзолата
```
