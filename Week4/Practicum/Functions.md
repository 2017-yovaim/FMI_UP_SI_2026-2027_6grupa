# Фунцкии
Определение:
Функцията е именуван блок код, който можеш да извикаш многократно. Тя взема входни данни (параметри), върши работа и може да върне резултат.

Защо се ползват:
-кода се пише еднократно и може да се използва многократно
-по-четим код
-разделяне на задачата на малки стъпки.

Структура:
```cpp
int add(int a, int b) {     // тип на резултата, име, параметри
    return a + b;           // тяло и върната стойност
}

int main() {
    int r = add(3, 4);      // извикване, r = 7
}
```
Още за функции:

Тип на връщане:
-може да бъде всякакъв, като има опция да не връща нищо(void)
+за void може да се напише return; и функцията приключва

Параметри:
-може да бъдат всякакви(int, double, char, ...)
-има различни видове начин на подаване:
```cpp
void byValue(int x)         { x = 10; }   // копие, оригиналът не се променя
void byRef(int& x)          { x = 10; }   // оригиналът се променя, не се създава копие
void byConstRef(const int& v) { }  // не се създава копие, не се променя
```

Константни функции
```cpp
-void f() const (member) - не променя обекта
void f(const T& x)	не променя аргумента
const T& f() - връща константен обект
```

Стойност по подразбиране
-може да задаваме стойности по подразбиране, но трябва да бъдат след всички параметри без стойност по подразбиране
-ако се подаде стойност на параметър със стойност по подразбиране при извикване, се използва него
```cpp
void greet(string name = "world") { cout << "Hello " << name; }
greet();        // Hello world
greet("Ani");   // Hello Ani
```

Декларация/дефиниция
```cpp
int add(int a, int b);        // декларация (прототип)

int main() { add(1, 2); }

int add(int a, int b) {       // дефиниция
    return a + b;
}
```

Предефиниране
-може да напишем функции с еднакви имена, но трябва да имат различен брой/вид параметри
