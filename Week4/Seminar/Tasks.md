# Семинар 4 - Функции. Задачи

***Важно!*** - **Функциите, които напишете, трябва да валидират входните си данни!**

<p><strong>Задача 1: </strong>Напишете функция, която приема цяло число и връща броя на цифрите му. Пример: </p>
<p>Вход: </p>

```
1234
```

<p>Изход: </p>

```
4
```

<p><strong>Задача 2: </strong>Напишете функция, която приема цяло число и връща сбора на цифрите му. Пример: </p>
<p>Вход: </p>

```
1234
```

<p>Изход: </p>

```
10
```

<p><strong>Задача 3: </strong>Напишете функция, която приема цяло положително число, което не завършва на 0, и връща числото, прочетено от дясно наляво ("обърнатото" число). Пример: </p>
<p>Вход: </p>

```
1234
```

<p>Изход: </p>

```
4321
```

<p><strong>Задача 4: </strong>Напишете функция, която приема цяло положително число и връща дали числото е полиндром, тоест дали се чете по един и същи начин от ляво надясно и от дясно наляво. Пример: </p>
<p>Вход: </p>

```
1234
```

<p>Изход: </p>

```
0
```
<p>Вход: </p>

```
121
```

<p>Изход: </p>

```
1
```

<p><strong>Задача 5: </strong>Напишете функция, която приема две цели положителни числа n и k, което не завършва на 0, и връща n, повдигнато на степен k. Пример: </p>
<p>Вход: </p>

```
2 3
```

<p>Изход: </p>

```
8
```

<p><strong>Задача 6: </strong>Напишете функция, която приема две цели положителни числа n и k, и връща дали k е суфикс на n, тоест дали последните цифри на n съвпадат с цифрите на k. Обърнете внимание, 
че едно число е суфикс само на себе си. Пример: </p>
<p>Вход: </p>

```
123 23
```

<p>Изход: </p>

```
1
```
<p>Вход: </p>

```
123 21
```

<p>Изход: </p>

```
0
```

<p><strong>Задача 7: </strong>Напишете функция, която приема две цели положителни числа n и k, и връща дали k е префикс на n, тоест дали първите цифри на n съвпадат с цифрите на k. Обърнете внимание, 
че едно число е префикс само на себе си. Пример: </p>
<p>Вход: </p>

```
123 12
```

<p>Изход: </p>

```
1
```
<p>Вход: </p>

```
123 13
```

<p>Изход: </p>

```
0
```

<p><strong>Задача 8: </strong>Напишете функция, която приема две цели положителни числа n и k, и връща дали k е инфикс на n, тоест дали някои цифри на n съвпадат с цифрите на k (в същия ред). Обърнете внимание, 
че едно число е инфикс само на себе си. Пример: </p>
<p>Вход: </p>

```
1234 23
```

<p>Изход: </p>

```
1
```
<p>Вход: </p>

```
1234 32

```

<p><strong>Задача 9: </strong>Напишете функция, която приема две цели числа и разменя стойностите им (swap). </p>

<strong>Задача 10: </strong>Напишете функция, която приема 3 цели положителни числа n, m и k, като (0 < n  m < 10000) и (0 < к < 10). Функцията не връща нищо, е извежда на стандартния изход всички числа в интервала 
[n, m], за които е вярно, че средното аритметично от техните цифри е по-голямо от k.
