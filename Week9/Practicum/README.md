## 1. Условни оператори

### 1.1 Релационни и логически оператори

| Оператор | Значение |
|---|---|
| `==`, `!=` | равно, различно |
| `<`, `>`, `<=`, `>=` | сравнения |
| `&&` | логическо И |
| `\|\|` | логическо ИЛИ |
| `!` | логическо НЕ |

- Резултатът от логически израз е `bool` (`true` = 1, `false` = 0). Всяка стойност, различна от 0, се счита за истина.
- **Съкратено оценяване (short-circuit):** при `a && b` ако `a` е лъжа, `b` не се изчислява. При `a || b` ако `a` е истина, `b` не се изчислява. 
- **Класическа грешка:** `=` е присвояване, `==` е сравнение. `if (x = 5)` присвоява 5 на `x` и винаги е истина.
- Реални числа (`float`, `double`) не се сравняват с `==`. Използва се `abs(a - b) < EPSILON`, където const double EPSILON = 1e-9.


### 1.2 if / else if / else

```cpp
if (condition1) {
    // изпълнява се, ако condition1 е истина
} else if (condition 2) {
    // ако condition1 е лъжа, а condition2 е истина
} else {
    // във всички останали случаи
}
```

- Проверките се правят отгоре надолу и се изпълнява само първият истинен клон.
- Ако клонът е един оператор, фигурните скоби могат да се пропуснат, но е препоръчително да се пишат винаги.
- **Dangling else:** `else` принадлежи към най-близкото предходно `if`, независимо от отстъпите.

### 1.3 switch

```cpp
switch (num) {      // цяло число или char (не double, не символен низ)
    case 1:
        cout << "one";
        break;        // без break изпълнението "пропада" в следващия case
    case 2:
    case 3:           // един код за 2 и 3
        cout << "two or three";
        break;
    default:          // по избор, изпълнява се, ако няма съвпадение
        cout << "other";
}
```

- Стойностите в `case` трябва да са константи по време на компилация и различни помежду си.
- Липсата на `break` е най-честата грешка при `switch`.

### 1.4 Тернарен оператор `?:`

```cpp
int max = (a > b) ? a : b;   // условие ? ако_истина: ако_лъжа
```

## 2. Цикли и оператори за цикъл

### 2.1 Видове цикли

```cpp
// while: проверка ПРЕДИ тялото (може да не се изпълни нито веднъж)
while (условие) {
    // тяло
}

// do-while: проверка СЛЕД тялото (изпълнява се поне веднъж)
do {
    // тяло
} while (условие);        

// for: инициализация; условие; промяна
for (int i = 0; i < n; i++) {
    // тяло
}
```

- `for` се използва, когато броят на повторенията е известен. `while` се използва, когато се повтаря до настъпване на някакво условие. `do-while` е подходящ за четене с валидация на входа.
- Редът в `for`: инициализацията се изпълнява веднъж, после се проверява условието, изпълнява се тялото, изпълнява се промяната и отново се проверява условието.
- Всяка от трите части на `for` може да се пропусне. `for (;;)` е безкраен цикъл.
- Променлива, обявена в `for`, живее само в него.

### 2.2 Оператори за промяна на цикъла (jump statements)

- `break` прекъсва най-вътрешния цикъл (или `switch`) и продължава след него.
- `continue` прекратява текущата итерация и преминава към следващата. При `for` се изпълнява частта за промяна, при `while` се проверява условието (затова при `while` трябва да сте променили брояча **преди** `continue`, иначе циклът става безкраен).
- `return` излиза от цялата функция.

### 2.3 Оператори `++`, `--`, `+=` и др.

- `i++` (постфиксен) връща старата стойност и после увеличава. `++i` (префиксен) първо увеличава и връща новата.
- Пример: при `int i = 5; int a = i++;` получаваме `a = 5, i = 6`. При `int b = ++i;` получаваме `b = 7, i = 7`.
- Съкратени оператори: `+=`, `-=`, `*=`, `/=`, `%=`.
- Целочислено деление: `7 / 2 == 3`, `7 % 2 == 1`. Ако искате реален резултат: `7 / 2.0`.

### 2.4 Вложени цикли

Вътрешният цикъл се изпълнява изцяло за всяка итерация на външния. Общият брой итерации е произведението на отделните броячи.

```cpp
for (int i = 1; i <= n; i++) {        // обхождане на двумерен масив
    for (int j = 1; j <= m; j++)
        cout << matrix[i][j];
    cout << endl;
}
```

## 3. Референции и указатели

### 3.1 Указатели

Указателят е променлива, която **съхранява адрес** на друга променлива.

```cpp
int x = 10;
int* p = &x;     // p съдържа адреса на x
cout << *p;      // 10: дерефериране (стойността на адреса)
*p = 20;         // променя x, сега x = 20
cout << p;       // изписва адрес
```

- `&` пред променлива е **адрес на** самата променлива. `*` пред указател е **стойността, към която сочи** указателят. В декларация `int* p` означава, че `p` е указател.
- Неинициализиран указател съдържа произволен адрес и е опасен. Празният указател е `nullptr`. Преди дерефериране се проверява `if (p != nullptr)`.
- Типът на указателя определя колко байта се четат и колко се прескача при аритметика. 

### 3.2 Указатели и масиви

- Името на масив е константен указател към първия му елемент: `a == &a[0]`.
- Масивите се подават по референция като аргументи на функция.


### 3.3 Референции

Референцията е **псевдоним (друго име)** на съществуваща променлива.

```cpp
int x = 5;
int& r = x;      // r е друго име на x
r = 10;          // x == 10
r++;             // x == 11
```

- Задължително се инициализира при деклариране (`int& r;` е грешка).
- След инициализацията не може да бъде пренасочена към друга променлива. 
- Няма "нулева референция" и няма референция към референция.
- Използва се при параметри (да се променя оригиналът или да се избегне копирането) и при връщане на резултат.

## 4. Функции

### 4.1 Дефиниция, декларация, извикване

```cpp
int maxOf(int a, int b);        // декларация 

int main() {
    cout << maxOf(3, 7);        // извикване
    return 0;
}

int maxOf(int a, int b) {       // дефиниция
    return a > b ? a : b;
}
```

- Общ вид: `тип_на_резултата име(параметри) { тяло }`.
- Функция, която не връща стойност, е от тип `void`. Може да съдържа `return;` без израз.
- Функцията трябва да е **декларирана преди първото ѝ използване**. Затова се пишат декларации или функциите се подреждат преди `main`.
- `return` веднага прекратява функцията. Ако функция с тип, различен от `void`, достигне края си без `return`, поведението е недефинирано.
- Формални параметри са тези в дефиницията. Фактически параметри (аргументи) са тези при извикването.

### 4.2 Предаване на параметри

| Начин | Запис | Какво се случва |
|---|---|---|
| По стойност | `void f(int x)` | функцията работи с **копие**, оригиналът не се променя |
| По референция | `void f(int& x)` | `x` е друго име на оригиналната променлива, промените се виждат навън |
| По указател | `void f(int* x)` | подава се адрес, промяната става чрез `*x` |
| По константна референция | `void f(const int& x)` | без копиране и без право на промяна |

```cpp
void swapVal(int a, int b) { int t = a; a = b; b = t; }       // НЕ работи
void swapRef(int& a, int& b) { int t = a; a = b; b = t; }     // работи

int x = 1, y = 2;
swapVal(x, y);    // x = 1, y = 2
swapRef(x, y);   // x = 2, y = 1
```

### 4.3 Масиви като параметри

```cpp
void fill(int arr[], int n);   
```

- Масивът **не се копира**. Подава се адресът на първия елемент, затова промените във функцията се отразяват на оригинала.
- Размерът **трябва да се подава отделно** (`size`).
- Ако функцията не бива да променя масива, се пише `const int arr[]`.

### 4.4 Обхват и живот на променливите

- Локалните променливи съществуват само в блока, в който са обявени, и не се инициализират автоматично.
- Глобалните променливи са видими навсякъде и се нулират по подразбиране, но е добра практика да се избягват.
- Локална променлива **скрива** (shadowing) глобална със същото име.
- Не се връща адрес или референция към локална променлива. След края на функцията тя не съществува.

### 4.5 Параметри по подразбиране и предефиниране на функции (function overloading)

```cpp
int power(int base, int exp = 2);      // power(3) връща 9

int add(int a, int b);                  // предефиниране 
double add(double a, double b);         // еднакво име, различни параметри
```

- Параметрите по подразбиране са най-вдясно в списъка.
- Предефенираните функции (finction overloading)се различават по броя и/или типа на параметрите, но **не само по върнатия тип**.

## 5. Масиви

### 5.1 Особености

Масивът е последователност от елементи **от един и същи тип**, разположени **последователно в паметта**.

```cpp
int a[5];                    // 5 елемента с неопределени стойности
int b[5] = {1, 2, 3};        // {1, 2, 3, 0, 0}: останалите се нулират
int c[] = {4, 5, 6};         // размерът се определя от инициализацията (3)
int d[5] = {};               // всички нули
```

- Индексите са от `0` до `size - 1`. Първият елемент е `a[0]`, последният е `a[n - 1]`.
- **Няма проверка на границите.** Достъп до `a[5]` при размер 5 е недефинирано поведение и често е причина за странни грешки.
- Размерът е константа по време на компилация (стандартният C++ не позволява `int a[n]` с променлива `n`).
- Масивите не могат да се присвояват (`a = b` е грешка) и не могат да се сравняват с `==`. Копира се елемент по елемент.
- Името на масива е адрес на първия му елемент. Затова при подаване на масив във функция се подава адрес, а не копие.
- Броят елементи на масив в същата област на видимост: `sizeof(a) / sizeof(a[0])`. Във функция това не работи, защото параметърът е указател.

### 5.2 Въвеждане, извеждане, обхождане

```cpp
const int MAX = 100;
int a[MAX], n;
cin >> n;
for (int i = 0; i < n; i++) cin >> a[i];
for (int i = 0; i < n; i++) cout << a[i] << ' ';
```

### 5.3 Шаблони

```cpp
// Максимум (минимумът е аналогично)
int mx = a[0];
for (int i = 1; i < n; i++)
    if (a[i] > mx) mx = a[i];

// Линейно търсене: индекс на x или -1
int found = false;
for (int i = 0; i < n; i++)
    if (a[i] == x) { 
        found = true; 
        break; 
}

// Обръщане на масива (разменя се от двата края)
for (int i = 0; i < n / 2; i++) {
    int t = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = t;
}

// сортиране на масив чрез метода за пряка селекция (Selection sort)
void selectionSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i;
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) minIdx = j;
        }
        swap(arr[i], arr[minIdx]);
    }
}


// Проверка дали е сортиран във възходящ ред
bool sorted = true;
for (int i = 0; i + 1 < n; i++)
    if (a[i] > a[i + 1]) { 
        sorted = false; 
        break; 
}
```

## 6. Двумерни масиви (матрици)

### 6.1 Особености

```cpp
int m[3][4];                          // 3 реда, 4 колони
int t[2][3] = {{1, 2, 3}, {4, 5, 6}}; // инициализация по редове
int z[2][3] = {};                     // всички нули
```

- Първият индекс е редът, вторият е колоната. `m[i][j]` е елементът на ред `i`, колона `j`. Индексите започват от 0.
- В паметта матрицата се съхранява **ред след ред** (row-major).
- Обхождането е с два вложени цикъла. Външният е по редовете, вътрешният е по колоните.

```cpp
for (int i = 0; i < n; i++) { // readMatrix()
    for (int j = 0; j < m; j++)
        cin >> mat[i][j];
}
for (int i = 0; i < n; i++) { // printMatrix()
    for (int j = 0; j < m; j++)
        cout << mat[i][j] << ' ';
    cout << endl;
}
```

### 6.2 Важни свойства (квадратна матрица `n x n`)

| Какво | Условие |
|---|---|
| Главен диагонал | `i == j` |
| Вторичен диагонал | `i + j == n - 1` |
| Над главния диагонал | `j > i` |
| Под главния диагонал | `j < i` |
| Ред `k` | `m[k][j]` за всяко `j` |
| Колона `k` | `m[i][k]` за всяко `i` |

### 6.3 Шаблони

```cpp
// Сума по редове
for (int i = 0; i < n; i++) {
    int s = 0;
    for (int j = 0; j < m; j++) s += mat[i][j];
    cout << s << endl;
}

// Сума по колони (външният цикъл е по колоните)
for (int j = 0; j < m; j++) {
    int s = 0;
    for (int i = 0; i < n; i++) s += mat[i][j];
    cout << s << endl;
}

// Сума на главния диагонал (само за квадратни матрици)
int d = 0;
for (int i = 0; i < n; i++) d += mat[i][i];

// Сума на вторичния диагонал (само за квадратни матрици)
int d2 = 0;
for (int i = 0; i < n; i++) d2 += mat[i][n - 1 - i];

// Транспониране на матрица
int result[cols][rows];// опригиналната матрица е matrix[rows][cols]
for (int i = 0; i < rows; i++)
    for (int j = 0; j < cols; j++) {
        result[j][i] = matrix[i][j];
    }

// Диагонално обхождане
void printMatrixDiagonals(const int matrix[ROWS][COLS]) {
    // Обхождаме диагоналите, които започват от първата колона
    for (int startRow = 0; startRow < ROWS; ++startRow) {
        int row = startRow;
        int col = 0;
        // Преминаваме диагонално нагоре вдясно
        while (row >= 0 && col < COLS) {
            cout << matrix[row][col] << " ";
            row--;
            col++;
        }
        cout << endl;
    }

    // Обхождаме диагоналите, които започват от последния ред (без първата клетка)
    for (int startCol = 1; startCol < COLS; ++startCol) {
        int row = ROWS - 1;
        int col = startCol;
        // Преминаваме диагонално нагоре вдясно
        while (row >= 0 && col < COLS) {
            cout << matrix[row][col] << " ";
            row--;
            col++;
        }
        cout << endl;
    }
}

// Умножение на матрици: C[n][p] = A[n][m] * B[m][p]
for (int i = 0; i < n; i++)
    for (int j = 0; j < p; j++) {
        C[i][j] = 0;
        for (int k = 0; k < m; k++)
            C[i][j] += A[i][k] * B[k][j];
    }


```

- При умножение броят колони на `A` трябва да е равен на броя редове на `B`.

### 6.4 Двумерен масив като параметър на функция

```cpp
const int COLS = 10;
void print(int mat[][COLS], int rows, int cols);   // колоните са задължителни
```

Първата размерност може да се пропусне, но всички следващи трябва да са зададени с константа.

## 9. Важни особености за качествен и четим код

- без magic numbers – използване на константи
- валидация на входни данни и при грешка извеждане на подходящо съобщение
- проверка на границите на масив или матрица (да не се позволява излизане извън границите на размера)
- разделяне на логиката във функции (една функция трябва да върши само една работа, в противен случай разделяме логиката в няколко помощни функции)
- когато не променяме дадена променлива, масив или матрица, ги подаваме като константен параметър във функция.
- използваме разбираеми имена за променливи и функции, които описват какво правят те (да се избягват имена от типа на int a; или void f())
- за четене на вход или принтиране на някакъв резултат (елементи на масив или матрица) винаги пишем оделни функции
- когато искаме да променяме оригиналната променлива във функция я подаваме по референция
- не използваме using namespace std; (вместо това пишем std::cin и std::cout)
- пишем сигнатурата на функцията по същия начин, по който е зададена в условието на задачата (ако не е зададена, пишем собствена сигнатура)
