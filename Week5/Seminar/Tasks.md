# Семинар 5 - Статични едномерни масиви. Задачи

<p><strong>Задача 1: </strong>Напишете функция, която приема целочислен масив и намира стойността и индекса на най-големия елемент в масива. </p>

<p><strong>Задача 2: </strong>Напишете функция, която приема целочислен масив и цяло число, и проверява дали числото се съдържа в масива - да връща индекса на елемента, ако числото се съдържа, или -1, ако не 
  се съдържа. (линейно търсене). </p>

<p><strong>Задача 3: </strong>Напишете функция, която приема целочислен масив, сортиран възходящо, и цяло число. Функцията да проверява дали числото се съдържа в масива - да връща индекса на елемента, ако числото 
се съдържа, или -1, ако не се съдържа (двоично търсене). </p>

<p><strong>Задача 4: </strong>Напишете функция, която приема 2 целочислени масива и връща скаларното им произведение (сборът от произведенията на елементите на еднаквите индекси). Пример: </p>
Вход:

```
2 4 6 1 7
3 6 1 2 0
```

Изход:
```
38
```

Пояснение: 2\*4 + 4\*6 + 6\*1 + 1\*2 + 7\*0 = 38

<p><strong>Задача 5: </strong>Напишете функция, която приема целочислен размер и връща дали масивът е симетричен (дали се чете еднакво от ляво надясно и от дясно наляво). Пример: </p>
Вход:

```
2 4 3 4 2
```

Изход:
```
1
```

Вход:

```
2 4 6 1 7
```

Изход:
```
0
```

<p><strong>Задача 6: </strong>Напишете функция, която приема целочислен масив и проверява дали масивът има еднакви (повтарящи се) елементи. Пример: </p>
Вход:

```
2 4 3 4 2
```

Изход:
```
1
```

Вход:

```
2 4 6 1 7
```

Изход:
```
0
```


<p><strong>Задача 7: </strong>Напишете функция, която приема от стандартния вход поток оценки - цели числа в интервала [2, 6] - докато не се въведе число извън интервала. Функцията да връща средно аритметичното на 
въведените оценки. Подсказка: хистограма </p>


<p><strong>Задача 8: </strong>Напишете функция, която приема целочислен масив и два индекса from и to. Фунцкяита да премести елемента с индекс from на индекса to, без да променя наредбата на останалите елементи. 
Пример: </p>
Вход: 

```
[1 2 3 4 5] 1 4
```

Изход:
```
[1 3 4 5 2]
```

Вход:

```
[1 2 3 4 5] 4 2
```

Изход:
```
[1 2 5 3 4]
```

<p><strong>Задача 9: </strong>Напишете функция, която приема целочислен масив, число, и индекс. Функцията да вмъкне числото в масива на посочения индекс (предполагаме, че в масива има място). Пример: </p>
Вход: 

```
[1 2 3 4 5] 6 3
```

Изход:
```
[1 2 3 6 4 5]
```

<p><strong>Задача 10: </strong>Напишете фунцкия, която приема 2 целочислени масива, сортирани възходящо. Функцията да върне трети масив, който съдържа елементите на двата масива, също сортирани възходящо (merge 
на 2 сортирани масива). Пример: </p>
Вход: 

```
[1 2 3 4 5]
[2 6 8 9]
```

Изход:
```
[1 2 2 3 4 5 6 8 9]
```
