Вход:
```
10 1
```
Изход:
1
```
10 0
```
Изход: 0

 
Задача 2:
Дадени са n и k. Изведете три числа: n с включен бит k, с изключен бит k и с обърнат бит k.

Вход: 
```
9 2
```
Изход: 13 9 13
<details>
<summary>Hint</summary>
Обяснение: 9 = 1001. Включен бит 2 дава 1101 = 13, изключен остава 1001 = 9, обърнат дава 1101 = 13.
</details>

Задача 4:
Дадено е число от 0 до 255, което се разглежда като 8-битово. Обърнете реда на битовете му (първият става последен) и изведете полученото число.

Вход:
```
 13
 ```
Изход: 176

Обяснение: 13 = 00001101, обърнато е 10110000 = 176.


Задача 5:
Дадени са масив от n числа (n <= 20) и число S. Намерете колко подмножества на масива имат сума S. Използвайте всички маски от 0 до (1 << n) - 1, където всеки бит показва дали елементът участва в подмножеството.
```
4
1 2 3 4
5
```
Изход: 3
<details>
<summary>Hint</summary>
За всяка маска минаваш през всичките n бита, събираш елементите с единица и сравняваш сумата със S
</details>
