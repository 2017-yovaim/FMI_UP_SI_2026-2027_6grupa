# Задачи за подготовка за първо контролно

## Задача 1

Какво ще изведе дадената операция?

```cpp
for (int i = 0; i < 100; i++) {
    for (int i = 0; i < 100; i++) {
        cout << i << " ";
    }
    cout << endl;
}
```

<details>
<summary>Покажи отговор</summary>

100 реда, всеки с числата `0 1 2 ... 99 `. Вътрешното `i` скрива външното, затова цикълите не си пречат.

</details>

## Задача 2

Какво прави следната функция?

```cpp
void swap(double a, double b) {
    double c = a;
    a = b;
    b = c;
}
```

<details>
<summary>Покажи отговор</summary>

Нищо видимо. Параметрите са **по стойност** (копия), разменят се само копията. Поправка: `void swap(double& a, double& b)`.

</details>

## Задача 3

Какво ще върне следната функция?

```cpp
double f() {
    double num1 = 4;
    double num2 = 4 / 7;
    return (num2-- = ++++num1 + 2);
}
```

<details>
<summary>Покажи отговор</summary>

**Грешка при компилация.** `num2--` връща rvalue и не може да е вляво от `=`.

Бележки: `4 / 7` е `0`; `++++num1` е валидно и дава `6`, т.е. дясната страна е `8`.

</details>

## Задача 4

Какво ще изведе този код на конзолата?

```cpp
#include <iostream>

int main() {
    int x = 2;
    switch (x) {
        case 1: std::cout << "One" << std::endl;
        case 2: std::cout << "Two" << std::endl;
        case 3: std::cout << "Three" << std::endl;
        default: std::cout << "Default" << std::endl;
    }
}
```

<details>
<summary>Покажи отговор</summary>

```
Two
Three
Default
```

Няма `break`, затова изпълнението пропада надолу (fall-through).

</details>

## Задача 5

Какво ще изведе този код на конзолата?

```cpp
#include <iostream>

int main() {
    for (int i = 0; i < 5; i++);
    {
        std::cout << "i = " << i << std::endl;
    }
}
```

<details>
<summary>Покажи отговор</summary>

**Грешка при компилация.** `;` след `for(...)` прави тялото празно. Блокът е отделен, а `i` не съществува извън `for`.

</details>

## Задача 6

Какво ще изведе този код на конзолата?

```cpp
#include <iostream>

int main() {
    int i = 10;
    while (i = 5) {
        std::cout << i << " ";
        i--;
    }
}
```

<details>
<summary>Покажи отговор</summary>

**Безкраен цикъл:** `5 5 5 5 ...`

`i = 5` е присвояване със стойност 5 (истина). При всяка проверка `i` пак става 5.

</details>

## Задача 7

Какво ще изведе този код на конзолата?

```cpp
int i = 0;
while (++i, ++i < 14) {
    do
    {
        cout << i * 2 << endl;
    } while (i++ < 5);
}
```

<details>
<summary>Покажи отговор</summary>

```
4
6
8
10
16
22
```

- Първа проверка: `i` става 2. Вътрешният цикъл печата 4, 6, 8, 10 (при `i`=2,3,4,5) и излиза с `i=6`.
- Втора проверка: `i=8`, печата 16, излиза с `i=9`.
- Трета: `i=11`, печата 22, излиза с `i=12`.
- Четвърта: `i=14`, `14 < 14` е лъжа, край.

</details>

## Задача 8

Напишете еквивалентен код на следния програмен фрагмент, като използвате оператор `switch` веднъж (и не използвате `if`):

```cpp
int b;
if (b == 2) cout << "two";
if (b != 5) cout << "25";
else if (b > 5) cout << "huge";
else cout << "fail";
```

<details>
<summary>Покажи отговор</summary>

Случаи: `b==2` → `two25`; `b==5` → `fail`; иначе → `25`. Клонът `"huge"` е недостижим.

```cpp
switch (b) {
    case 2:
        cout << "two";
        // пропада към default
    default:
        cout << "25";
        break;
    case 5:
        cout << "fail";
        break;
}
```

</details>

## Задача 9

Напишете еквивалентен код на следния програмен фрагмент, като използвате оператор `switch` веднъж (и не използвате `if`):

```cpp
(x == 10) && cout << "xyz";
((x == 4) || (x == 6)) ? cout << "this" :
((x >= 6) && (x <= 8)) ? cout << "correct" : cout << "undef";
```

<details>
<summary>Покажи отговор</summary>

За `x==10` се печата `xyz` и после `undef`. За 6 печата `this` (хваща се първо). Само 7 и 8 дават `correct`.

```cpp
switch (x) {
    case 10:
        cout << "xyz";
        cout << "undef";
        break;
    case 4:
    case 6:
        cout << "this";
        break;
    case 7:
    case 8:
        cout << "correct";
        break;
    default:
        cout << "undef";
}
```

</details>

## Задача 10

Опишете последователно точно какво ще изведе на екрана следният програмен фрагмент. Обосновете писмено подробно отговора си.

```cpp
for (int i = 9; i <= 16; cout << i << endl) i++;
```

<details>
<summary>Покажи отговор</summary>

```
10
11
12
13
14
15
16
17
```

Тялото е `i++`, а печатането е в частта „стъпка“ и се изпълнява **след** тялото. При `i=16` проверката е вярна, тялото прави `17`, печата се 17, после `17 <= 16` е лъжа.

</details>

## Задача 11

Опишете последователно точно какво ще изведе на екрана следният програмен фрагмент. Обосновете писмено подробно отговора си.

```cpp
for (int i = -10; i++; i++) cout << i << ' ' << endl;
```

<details>
<summary>Покажи отговор</summary>

```
-9
-7
-5
-3
-1
```

(след всяко число има интервал преди новия ред)

Условието `i++` проверява старата стойност (0 е лъжа), а `i` расте веднага. Заедно със стъпката `i++` за една итерация `i` расте с 2. При `i=0` условието е лъжа и цикълът свършва.

</details>

## Задача 12

Какво ще изведе програмата на всеки от редовете?

```cpp
int x = 10;
{
    int x = 20;
    {
        int x = x + 5;
        cout << x << " ";
    }
    cout << x << " ";
}
cout << x << endl;
```

<details>
<summary>Покажи отговор</summary>

`<неопределена стойност> 20 10`

В `int x = x + 5;` новото `x` вече е във видимост, т.е. чете се неинициализирано `x` (недефинирано поведение, не е 25).

</details>

## Задача 13

Какво ще се изведе?

```cpp
int a = 0;
int b = 2;

if (a++ && ++b) {
    b += 5;
} else {
    a += b++;
}

cout << a << b;
```

<details>
<summary>Покажи отговор</summary>

`33`

`a++` дава 0 (лъжа), `a=1`. Short-circuit: `++b` не се изпълнява. В `else`: `a = 1 + 2 = 3`, `b = 3`.

</details>

## Задача 15

Какво ще се изведе?

```cpp
int x = 4;
int y = 7;
int ans = (x > y) ? (x - y) : ((x + y == 11) ? (x * y) : (y - x));

cout << ans;
```

<details>
<summary>Покажи отговор</summary>

`28`

`x > y` е лъжа; `x + y == 11` е истина, значи `x * y = 28`.

</details>

## Задача 16

Обяснете какво се случва.

```cpp
int val = 10;
for (int i = 3; i > 0; i--) {
    val -= i;
}
cout << val;
```

<details>
<summary>Покажи отговор</summary>

`4`

10 − 3 = 7, 7 − 2 = 5, 5 − 1 = 4.

## Задача 19
